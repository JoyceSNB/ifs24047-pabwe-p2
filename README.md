# Deskripsi Project

Project ini merupakan implementasi Praktikum 2 PABWE 2026 dengan
studi kasus website multi-halaman untuk perusahaan jasa
**Artificial Intelligence (AI)**.

Website menggunakan brand **NexaLab** sebagai identitas perusahaan.
NexaLab merupakan perusahaan jasa teknologi yang menyediakan beberapa
solusi berbasis AI dan teknologi digital, seperti:

- Chatbot & Virtual Assistant
- Automasi Proses
- Data & Machine Learning
- Computer Vision

Project terdiri dari empat halaman utama yang menggunakan pendekatan
styling berbeda sesuai ketentuan praktikum:

1. Landing Page menggunakan HTML + CSS murni
2. Blog menggunakan Bootstrap 5 + Bootstrap Icons
3. Detail Blog menggunakan Bootstrap 5 + Bootstrap Icons
4. CV menggunakan Tailwind CSS 4

Seluruh halaman saling terhubung melalui sistem navigasi.
